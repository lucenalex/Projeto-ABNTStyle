# Projeto ABNTStyle — protótipo histórico (2023)

> **Estado:** legado experimental, sem manutenção ativa identificada. Este repositório registra uma etapa antiga do trabalho de implementação de formatação ABNT em LaTeX. **Não é uma ferramenta certificada pela ABNT e não deve ser presumida compatível com as edições atuais das normas.**

## Conteúdo preservado

- `abntstyle.sty` — código-fonte do protótipo.
- `abntstyle.tex` — arquivo auxiliar de demonstração.
- `LICENSE` — licença AGPL-3.0 declarada nesta etapa.
- `.gitignore` — regras históricas de artefatos LaTeX.

## Situação e próximo passo

Não há evidência, neste repositório, de cobertura normativa completa, suíte atual de regressão ou rotina de publicação. Mantenha-o para rastreabilidade e estudo da evolução da implementação. **Candidato a arquivamento**, após conferir dependências e direitos de redistribuição; não exclua o histórico.

Os desenvolvimentos posteriores constituem linhas distintas e exigem comparação de código e licenças antes de qualquer reutilização. O código presente permanece intocado nesta proposta organizacional.
